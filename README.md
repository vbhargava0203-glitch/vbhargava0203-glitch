### Manual setup

- [ ] Replace the clearly marked [ADD DATA] placeholders with repository URLs, project status details, the 3D preview, and email address.
- [ ] To enable the contribution snake, copy the YAML below into `.github/workflows/snake.yml` in that repository, enable GitHub Actions, then run the workflow once. A single README cannot execute a GitHub Actions workflow; the complete source is included here for convenience.
- [ ] Confirm the repository’s Actions settings permit the workflow to write to the `output` branch. The workflow grants `contents: write` to its token.
- [ ] External animation, icon, and statistics images depend on their hosted services being available.

### Contribution snake workflow

```yaml
name: Generate contribution snake

on:
  schedule:
    - cron: "17 2 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - name: Generate light and dark SVGs
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: vbhargava0203-glitch
          outputs: |
            dist/github-contribution-grid-snake.svg?palette=github-light
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - name: Publish SVGs to the output branch
        uses: crazy-max/ghaction-github-pages@v5
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
